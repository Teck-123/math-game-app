# math-game-app

# Description
Math Quiz Gaming A pp is programmed to make learning mathematics nore engaing and enjoyable for children, especially those in rural schools where they lack interactive learning tools.
Its main focus is to improve students' math skills in addition, subtraction, division and multiplication.
It aim in improving their speed and accuracy while providing teachers with simple and fun teaching methods.

# Features
- Math questions covering addition, subtraction, division and multiplication.
- Multiple levels: eassy, meduin and hard.
- Rewards to motivate studenys after passing each level.

# Technologies used
- HTML: to structure and layout.
- CSS: to style and design the game for engaging the children.
- DBJSON: json based system to store the question, levels and reward data. 
- JAVASCRIPT: core game logics, questions scoring and level management.
